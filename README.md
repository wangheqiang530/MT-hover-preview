# MT悬停大图

给 [M-Team](https://kp.m-team.cc)（馒头 PT）种子列表用的脚本猫 / 油猴脚本：**鼠标悬停在种子缩略图上，自动弹出大图；移开自动收起**，不用再点开原生预览、也不用手动点遮罩关闭。

> 大图会主动避开鼠标所在的位置——图始终画在缩略图矩形之外，不会盖住你正在指的地方。

![效果示意](assets/hover-preview-demo.png)

## 解决的问题

M-Team 种子列表每行最左侧的缩略图用的是 antd 的 `Image` 组件：

- 想看大图必须**点击**，弹出的是站点原生预览；
- 原生预览会**锁滚动**，必须点遮罩才能关掉；
- 一屏几十行，逐行点击极其低效。

本脚本把「点击 → 弹窗 → 点遮罩关闭」换成了「悬停 → 大图 → 移开消失」。

## 特性

- **悬停即看**：默认 120ms 后弹出，快速划过不会闪。
- **大图**：等比放大到可用区域的极限，最高可占屏幕 90% 以上高度。
- **不挡鼠标**：视口被切成「右 / 左 / 下 / 上」四块候选区，大图只在缩略图矩形之外绘制。
- **贴边智能翻转**：缩略图靠左边就往右展开，靠右边就自动翻到左侧，上下空间大时改放上下。
- **无封面跳过**：没有封面的种子（站点用 `emptyImg.svg` 占位）不会弹出一张破图。
- **滚动自动收起**：滚动时立即收起并短暂忽略悬停，不会跟着行一路乱闪。
- **不干扰原生功能**：点击缩略图仍然打开站点原生的全屏预览，此时脚本主动让位。
- **SPA 友好**：翻页、切分类、改筛选后重新渲染的行自动生效，无需刷新。
- **零依赖**：`@grant none`，不调用任何 GM API，直接跑在页面里。

## 安装

### 方式一：一键安装（推荐）

先装 [ScriptCat（脚本猫）](https://scriptcat.org) 或 Tampermonkey，然后打开下面的链接，扩展会接管安装：

```
https://raw.githubusercontent.com/wangheqiang530/MT%E6%82%AC%E5%81%9C%E5%A4%A7%E5%9B%BE/main/mteam-hover-thumbnail.user.js
```

### 方式二：手动

下载 [`mteam-hover-thumbnail.user.js`](mteam-hover-thumbnail.user.js)，拖进浏览器窗口，或粘贴到扩展的「新建脚本」里保存。

装好后打开 <https://kp.m-team.cc/browse/>，脚本会自动生效，**无需刷新以外的任何操作**。

## 使用

把鼠标停在任意种子的缩略图上即可。图会出现在缩略图右侧（放不下时自动换方向）。

## 可调参数

脚本开头的常量区（约第 46–56 行），想改手感直接改这几个数：

| 常量 | 默认值 | 作用 |
| --- | --- | --- |
| `SHOW_DELAY` | `120` | 悬停多久后弹出（ms），怕误触可以调大 |
| `HIDE_DELAY` | `140` | 移开后多久收起（ms） |
| `FADE_MS` | `150` | 淡入淡出时长（ms），需与 CSS 里的 transition 一致 |
| `SCROLL_MUTE` | `300` | 滚动后多久内忽略悬停（ms） |
| `SAFE_GAP` | `16` | 大图与缩略图的最小间距（px），保证不压住鼠标 |
| `EDGE` | `12` | 大图与视口边缘的留白（px） |
| `MIN_REGION` | `220` | 候选区域小于此尺寸就不优先考虑（px） |
| `MAX_UPSCALE` | `3` | 原图小于可用区域时最多放大几倍 |
| `FLAT_RATIO` | `0.62` | 拿不到原图尺寸时的占位比例 |

## 实现要点

写这类 antd 站点的悬停脚本有几个坑，记在这里省得重踩：

1. **命中的不是 `img`。** antd 在图片上盖了一层 `.ant-image-cover`，鼠标实际停在遮罩上，所以命中判断要顺着 `.ant-image` 容器反查子 `img`，不能只 `closest("img")`。
2. **预览层必须 `pointer-events: none`。** 一旦它接管鼠标事件，立刻触发 `mouseout`，形成「打开 → 移开 → 关闭 → 打开」的自激闪烁。
3. **滚动容器不是 `document`。** 站点真正的滚动条在 `.ant-layout`（`overflow-y: scroll`）上，滚动监听必须挂**捕获阶段**才收得到。
4. **滚动会补发 `mouseover`。** 浏览器在滚动后会重新计算 hover 目标，因此滚动期间要短暂忽略悬停，否则大图会跟着滚动的行一路乱闪。
5. **缩略图 URL 带签名。** 它指向 douban 原图（不是 52×70 的缩略尺寸），签名约 30 分钟过期，所以直接复用页面里那张图，不自己拼 URL、不缓存。
6. **避开鼠标用区域划分，不是跟随坐标。** 鼠标停在缩略图上时坐标固定，按「右/左/下/上」切视口贴边放置，比跟随鼠标偏移稳定得多，不会因微动而抖。

## 兼容性

- 浏览器：Chrome / Edge / Firefox 等支持 `UserScript` 的现代浏览器。
- 脚本管理器：ScriptCat（脚本猫）1.5+、Tampermonkey 4.0+。
- 匹配范围：`*://*.m-team.cc/*` 与 `*://m-team.cc/*`，站点任意页面、任意路径均生效。

## 已知限制

- 只在 M-Team 的种子列表结构（`img.torrent-list__thumbnail`）上生效；站点改版需要同步更新选择器。
- 因为缩略图在最左侧，大图基本都往右展开，会盖住列表内容区、右侧到屏幕边缘留一条空带——这是「不压住鼠标」的必然代价。
- 需要已登录站点，脚本本身不处理任何登录逻辑。
